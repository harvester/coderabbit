# coderabbit

Organization-wide [CodeRabbit](https://coderabbit.ai) configuration for the `harvester` org.

`.coderabbit.yaml` in this repository is the [central configuration](https://docs.coderabbit.ai/configuration/central-configuration). It applies to every repository in the org that doesn't have its own `.coderabbit.yaml`.

A repository can add its own `.coderabbit.yaml` with `inheritance: true` to add repo-specific rules on top of these defaults. See [configuration inheritance](https://docs.coderabbit.ai/configuration/configuration-inheritance).

> CodeRabbit must be installed on this repository so it can read the configuration.
